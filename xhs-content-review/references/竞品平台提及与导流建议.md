## 判断步骤与处理建议

先判断完整图文中“提到了谁、让读者做什么、去哪里、为达到什么目的”，再按 [导流主题](rules/XHS-R-006.md) 选取适用依据。检查标题、正文、图片 OCR、账号展示、二维码和水印之间的组合含义；不能读出目标或文字时单列待确认，不猜测。

| 已观察到的场景 | 判断与处理 |
|---|---|
| “我用微信和家人联系”“这双鞋是在淘宝买的” | 普通功能/经历描述，单凭平台名无须分级、删除或改写。仍需检查是否夹带其他风险。 |
| 对比不同平台的功能或说明来源 | 不仅凭平台名判导流；中性事实比较可以保留。若存在不实贬损，按竞品比较等实际适用主题另审，不给比较内容一律禁用的结论。 |
| “去B站搜我的账号看完整版”“到TikTok关注我” | 存在站外行为号召。记录号召原句、目标线索和发布场景，按通用/广告规则分别复核。删除跳转号召；需要解释的内容可实际补充到当前笔记后再改写，不能假称本篇已有完整内容。 |
| “加我微信领取资料”，并附可识别微信号 | 联合识别联系方式与领取目的，建议删除联系信息及站外领取号召。若适用规则已明确禁止且条件成立，可列必须禁用；否则说明高危条件，不能只靠“微信”二字作结论。 |
| “去橙色软件搜我”，但看不出具体平台 | 虽有站外引导线索，不能断言橙色软件就是抖音。可以按整体行为复核导流，目的地保持不明；不把目标未知本身算作违规。 |
| “猫狗都下单，点图里链接领取优惠” | 先核对是否确为平台购物语境，再识别链接和号召。建议去除有问题的站外行动链路；不能把“淘宝/京东”换成“猫/狗”后宣称合规。 |
| 引用或劝阻：“不要加陌生人的微信转账” | 不把被劝阻的行为当作作者在招揽，依据全句及图文反证判断。 |

## 分级、来源与报告定位

- **没有确认行为问题，仅有词表命中**：不生成高危/必须禁用问题，不把平台词自动标红。
- **有明确站外引导证据且有适用依据，但适用条件仍不明确**：可列高危，具体说明条件。缺少材料本身不等同有风险。
- **适用的明确禁止规则条件成立**：按判定协议列必须禁用。社区规范导流章节原文为“不鼓励”，不得单独升级成广告场景的明确禁止；广告原文仅在商业广告适用时使用。
- 相关来源为社区规范3.2.1、3.2.2以及现有商业广告材料中的第三方平台引导条款，原文与范围见导流主题。词表是作者加工线索，不能作为新增“官方禁止提及平台名”的条款。报告保留内部来源ID，HTML仍只展示来源名称及相关原文。
- 标红有问题的**完整表达或行动片段**，如“加我微信领取资料”，避免只标“微信”让用户误以为换名就能解决。同一问题来自正文还是图片 OCR 必须明确；图片还需编号与位置。

## 改写原则

建议应实际解决问题：删除不当站外号召、联系方式或交易入口；保留与主题有关的真实经历与信息。若建议改为站内呈现内容或官方渠道，必须先确认内容已提供、功能存在且场景允许。不得自行承诺资料、虚构站内链接或未经确认的合规渠道。

不提供“微信→薇信/绿色软件”“淘宝→猫”“平台名→emoji”等保留原导流意图的替换建议。用户自定义的删除平台名要求，与平台导流行为判断是两件事，分别说明。
