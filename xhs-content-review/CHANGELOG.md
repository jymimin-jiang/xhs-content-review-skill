# 更新说明

## 0.6.0 — 2026-10-29

- 新增8组竞品平台名称与用户提供的代称线索，独立维护结构化词表与语义判断说明。
- 区分普通提及、客观比较、联系方式和站外导流；歧义代称不强制关联平台，猫/狗不按单字子串匹配。
- 提供删除/实质改写建议，禁止以代称替换后保留导流意图。
- 保持官方来源与作者加工材料分开、正文与图片OCR分别定位；原965条材料词计数不变。


## 0.5.0 — 2026-10-29

- 新增 release.json：固定包标识、版本号、用户数据结构版本、逐文件 SHA-256。
- 固定最新包名 xhs-content-review.zip，同时保留不可覆盖的版本包。
- 新增本地安装、更新、查看状态、备份和回退工具；Python 3.9+，无需第三方依赖。
- 用户敏感词、自定义规则、报告与内置文件隔离；升级不覆盖用户数据。
- 升级前备份代码与用户文件；回退只恢复 Skill，不覆盖后来新增的数据。
- 本地内置文件改动、损坏包、并发更新、数据版本不兼容时停止操作。
- 旧版须显式迁移；包内修改完整归档，用户设置合并前明确提示未生效。
- 不改变既有风险分级、来源显示、报告标题和免责声明要求。

## 0.4（历史包名 v0.4）

已包含可复制的用户输入模板、作者加工词库声明与文本/图片分离的 HTML 报告。旧包没有 release.json；使用旧版迁移流程。更早的包保留在发布目录作为历史归档。

后续版本采用 major.minor.patch：不兼容变更增加 major，兼容功能增加 minor，修复增加 patch。数据结构不兼容时必须提供明确迁移程序，本版仅支持 data_schema=1。
